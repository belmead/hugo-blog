# Fonts

Headlines use [Kurodenwa Dial](https://github.com/jz5/fonts-kurodenwadial), selected by the user. Other text uses [Kibernetyk Mono](https://pavlokilko.github.io/KibernetykMono/).

Font files are served locally from `public/fonts/`. Both families use the SIL Open Font License; their license files are included beside the fonts. No external font service is required.
