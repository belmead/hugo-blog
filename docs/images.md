# Blog imagery

Added preview photographs were replaced with a flat beige SVG placeholder at the user’s request. They are archived outside the public files in ignored `output/unused-preview-images/`.

`public/img/` and the favicon set were copied from the original blog repository. Original screenshots and server imagery remain. New uploads are saved in `public/uploads/`.

Post thumbnails, article images, and image-library previews use native lazy loading and asynchronous decoding. A selected homepage hero loads immediately.
